# Wfolio + авторский сайт NIKA VOLKOVA

## Что за сервис
- [Wfolio](https://wfolio.ru/) — конструктор сайтов и клиентских фотогалерей. Пример из присланного HTML: https://ilyapykin.ru/ (в исходном HTML указано `wfolio`).
- [Webflow](https://webflow.com/) — другой продукт, визуальный сайт-билдер.

## Рекомендуемая схема
**Отдельный сайт HTML/CSS/JS → GitHub Pages**, **закрытые клиентские галереи → Wfolio**. Так сохраняются все авторские сетки, эффекты, анимация и существующие инструменты Wfolio для передачи фото.

## Как подключить Wfolio
1. Создать личный аккаунт и клиентские галереи на Wfolio.
2. В `assets/js/data.js` указать реальный `email`, контакт и адрес публичного портфолио Wfolio.
3. Добавить ссылки на конкретные галереи Wfolio на страницы проектов или в письмо клиенту. Публичные портфолио/галереи показывать только с разрешения владельца фотографий.
4. Не встраивать длинные временные CDN-ссылки с `i.wfolio.ru` как постоянный источник картинок: формат выдачи сервиса может измениться. Хранить опубликованные изображения для сайта локально в `assets/img/` предпочтительнее.

## Ссылки на фотографии-заглушки
Все текущие **прямые** адреса изображений из Unsplash в `PHOTO_LINKS.csv` и в `assets/js/data.js`. Они включены в проект для демонстрации, а не как портфолио фотографа. Доступность и условия использования конкретного кадра следует проверить перед коммерческой публикацией.

## Замена изображения
Например, положить своё `assets/img/hero.webp` и заменить в `data.js` значение `images.hero.src` на `assets/img/hero.webp`. Для всех фотографий нужны описательные `alt`, разрешение автора и оптимизированный WebP/AVIF.

## Если нужен сайт именно внутри конструктора Wfolio
HTML-файлы из архива нельзя считать импортируемым шаблоном Wfolio. Дизайн надо отдельно воспроизвести из его доступных блоков. В текущих данных не подтверждена возможность импортировать произвольный HTML/CSS/JS-сайт как собственный шаблон Wfolio.
