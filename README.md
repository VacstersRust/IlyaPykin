# NIKA VOLKOVA — static editorial photography site

## Запуск
Откройте `index.html` в браузере либо `python -m http.server 8000` в папке проекта. Для GitHub Pages загрузите содержимое папки в репозиторий и выберите Deploy from a branch / main / root.

## Страницы
index.html — главная; portfolio.html — портфолио; project.html?series=portrait — пример фотосерии; about.html — фотограф; services.html — услуги; contact.html — заявка.

## Перед релизом
1. В `assets/js/data.js` замените `name`, `email`, `city` и все `images.*.src` на свои значения. Пример: `assets/img/portrait.webp`. Исходные фотографии Unsplash по внешним ссылкам используются только как **демо** и требуют проверки лицензий и доступности. При отсутствии интернета активируются локальные SVG-заглушки.
2. Укажите настоящую биографию, условия, права на изображения, контакты и сведения об авторе. Цифры и цены специально не выдуманы.
3. В проектной странице поменяйте демонстрационные тексты и изображения на настоящие связанные серии.
4. Форма заявки работает через mailto (почтовую программу пользователя); для настоящей отправки без email-клиента подключите Formspree, свой backend или аналог.
5. Добавьте политику обработки персональных данных и настройте сбор согласия перед запуском формы с серверной отправкой.
6. Шрифты загружаются через Google Fonts; при необходимости разместите разрешённые веб-шрифты локально.

## Структура
`assets/css/style.css` — токены, типографика, сетка, адаптивность, анимации. `assets/js/data.js` — контент/ссылки на фото. `assets/js/app.js` — общие шаблоны и навигация. `assets/img/*.svg` — офлайн-заглушки. Без сборщика и зависимостей JavaScript.


## Использование с Wfolio
Смотрите `WFOLIO_SETUP.md` и `PHOTO_LINKS.csv` — сервис, схема публикации, все прямые ссылки на демонстрационные фотографии и замена на свои.
